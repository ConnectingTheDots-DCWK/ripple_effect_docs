# Ripple Effect documentation

The source of [docs.ripplefx.app](https://docs.ripplefx.app): the documentation
for Ripple Effect, an editor for branching stories. Built with
[Astro](https://astro.build) and [Starlight](https://starlight.astro.build).

**Found a mistake, or something unclear?** Every page has an *Edit page* link
at the bottom that opens it here, ready for a pull request. For anything
bigger, [CONTRIBUTING.md](CONTRIBUTING.md) says how to run the site and what a
change should look like. Questions about the app itself, and bug reports, go to
[ripple_effect_support](https://github.com/ConnectingTheDots-DCWK/ripple_effect_support).
